# Agent Canvas support

Agent Canvas is free, MIT-licensed open-source software. Support happens in the
[GitHub issue tracker](https://github.com/tombelieber/app-canvas/issues).
There is no paid support plan or guaranteed response time.

## Report a problem

Search existing issues first. If the problem is new,
[open an issue](https://github.com/tombelieber/app-canvas/issues/new) with:

1. The installed version and operating system.
2. The command or screen you used, and the result you expected.
3. The actual result and a small reproduction using synthetic data.
4. Whether it happens in the bundled demo, your source-backed project, or a URL import.

Remove tokens, credentials, private URLs, application content and personal data
from logs, recordings and screenshots before sharing them. Do not upload a
private project to reproduce a problem. A minimal synthetic example is enough.

## Request a feature

Use the same issue tracker. Describe what you are trying to build or change,
where the current workflow stops, and what a useful result would look like.
An issue is a discussion, not a delivery commitment.

## Report a security vulnerability

Use [GitHub's private vulnerability reporting](https://github.com/tombelieber/app-canvas/security/advisories/new)
for a suspected security vulnerability. Do not post exploit details or secrets
in a public issue. Private reporting requires a GitHub account and does not
provide a guaranteed response time.

## Privacy and local controls

See [Privacy and usage analytics](telemetry.md) for the exact event contract,
opt-out controls, local preferences and the boundary between the public
synthetic demo and a real project. Analytics being unavailable does not prevent
using the canvas.

## Project identity

The product is called **Agent Canvas**. Its source repository remains
[`tombelieber/app-canvas`](https://github.com/tombelieber/app-canvas), so existing
source links and earlier releases continue to resolve. This is an independent
project; it is not affiliated with OpenHands, Figma, Anthropic or OpenAI.

The product website is [agent-canvas-app.pages.dev](https://agent-canvas-app.pages.dev/).
